# Kotodama

English ⇄ Japanese voice translator for Australians in Japan. This repository holds only the
built web app, published at **https://ausmodiar-ship-it.github.io/kotodama-web/**. It works with
no server: built-in phrases, 100,000 everyday sentences and a dictionary, all stored on the phone.

Open it in Safari, tap Share › Add to Home Screen, then open it once on Wi-Fi with
"Save for offline use" on. After that it works with no signal.
